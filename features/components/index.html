    Components¶

    Components make data or functionality available for external systems via the Connectivity Features or for reuse in other components.

    Platforms offer extended functionality for any component.

    Common Entity Attributes¶

    All entities share a set of common attributes that can be used to customize their behavior.

    Entities¶

    • Sensor

    • Text Sensor
